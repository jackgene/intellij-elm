# Elm Plugin for IntelliJ IDEs (WebStorm, IDEA, PyCharm, etc.)

<!-- Plugin description -->
Provides support for the Elm programming language.
<!-- Plugin description end -->

The main purpose of this fork is to maintain support for Elm 0.18, hence 3.x being the default branch.

## Install

1. Make sure JDK 17 or higher is installed.
2. `./gradlew clean buildPlugin`
3. In IDEA: Settings > Plugins > ⚙️ > Install Plugin from Disk...
4. Navigate to `build/distributions`
5. Select `Elm-3.5.x.zip` to install
